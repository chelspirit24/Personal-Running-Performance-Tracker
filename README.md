# Personal Running Performance Tracker 

A basic running tracker that tracks and visualizes my personal running performance over a year (08-2025 to 08-2026) using data exported directly from Apple Health.
This Jupyter Notebook (Running.ipynb) parses the raw Apple Health export.csv file, filters for running-specific metrics, and calculates daily running distance and pace (minutes per mile) to monitor my fitness progress and training trends over time. Using the running distance and pace data, it is visualized using line plots.
